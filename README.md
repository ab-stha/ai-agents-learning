An 8-week self-study programme to learn and consolidate my knowledge of AI agents, working from fundamentals up to a capstone project. I build everything by hand first (no agent frameworks) so I understand how the pieces work.

This programme follows a roadmap shared with me by @kungfusaini (https://github.com/kungfusaini). The code, notes and reflections are my own work.

Structure of the programme:
|week-01| Python refresh
|week-02| Machine learning basics
|week-03| LLM fundamentals
|week-04| Prompting & practical LLM patterns
|week-05| Agents & tool use
|week-06| Orchestration & Pi workflow
|week-07| RAG & knowledge agents
|week-08| Evaluation & capstone
